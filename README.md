\# Student Performance Prediction System



\## Project Overview

The Student Performance Prediction System is a Machine Learning project that predicts students' exam scores and classifies their academic performance using Linear Regression and Logistic Regression.



\## Objectives

\- Predict student exam scores.

\- Classify student performance.

\- Analyze factors affecting academic performance.

\- Provide predictions through an interactive Streamlit application.



\## Technologies Used

\- Python

\- Pandas and NumPy

\- Matplotlib and Seaborn

\- Scikit-learn

\- Jupyter Notebook

\- Streamlit

\- Joblib



\## Machine Learning Algorithms

1\. Linear Regression – Exam score prediction.

2\. Logistic Regression – Academic performance classification.



\## Dataset

Student Performance Factors dataset.

\## How to Run the Project



Install dependencies:



```bash

pip install -r requirements.txt

```



Run the Streamlit application:



```bash

streamlit run app.py

```



\## Performance Classification

\- Score below 65: Needs Academic Support.

\- Score 65 or above: Satisfactory Performance.



Note: The 65-point threshold is a project-defined classification threshold, not an official pass/fail standard.
